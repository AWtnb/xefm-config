# README

Config for [XeFM](https://github.com/crftwr/xefm).

This project uses [uv](https://docs.astral.sh/uv/).

To set up the development environment, run:

```
uv sync
```

To install, run:

```
uv run install.py
```

## Extensions

### [xefm-pdftool](https://github.com/AWtnb/xefm-pdftool)

Install:

```
xefm ext install github:AWtnb/xefm-pdftool
```

Upgrade:

```
xefm ext upgrade xefm-pdftool
```
