# README

Config for [XeFM](https://github.com/crftwr/xefm).



## Install

Run [`install.ps1`](./install.ps1) to create junction of `.xefm` to `$env:USERPROFILE/.xefm`.

## Development Setup

This project uses [uv](https://docs.astral.sh/uv/) to match the Python version bundled with keyhac.

To set up the development environment, run:

```
uv sync
```
